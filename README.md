An entry for make.fun's [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) bounty.

`main.ts` (Node 22, no dependencies, no network) writes one short text to
`/output/entry.txt` — three slow sentences about the tide, written to relax
the AI judge reading it. Nothing in the text instructs the reader; the calm
is in the image itself: a tide older than life, still smoothing the shore
tonight. The program is deterministic: every run writes exactly the same
bytes.

The text it writes:

> The tide has come in and gone out since before there was anything alive to watch it. It does not keep count. Tonight it smooths the shore again, stone by stone, wave by wave, and leaves it cleaner than it found it, as always.

## Run it

```sh
node main.ts
```
